The Inner Sanctum Connect — Browser Extension Privacy

Inner Sanctum
Operated by Pringle AI LLC

Effective date: September 12, 2026

The Inner Sanctum Connect is a read-only Chrome extension whose single purpose is to connect a fantasy-football league that a user is already authorized to access on ESPN or CBS to The Inner Sanctum so the site can provide league-, roster-, lineup-, matchup-, and availability-aware fantasy analysis.

Information handled by the extension

When a user asks to connect a league, the extension may read fantasy-league information from supported ESPN or CBS pages and read-only provider endpoints. This can include league and team identifiers, roster and player information, league settings, standings, schedules, matchup context, and provider-reported player availability.

The extension handles web activity only on the supported ESPN, CBS, and The Inner Sanctum pages needed to complete the user-requested connection.

Authentication information

The extension uses the user's existing authenticated fantasy-provider browser session. It does not collect ESPN or CBS passwords and does not ask users to paste passwords, cookies, authorization headers, Developer Tools output, SWID, or espn_s2 values into The Inner Sanctum.

For ESPN, the extension may read the SWID identifier locally from the authenticated ESPN page when needed to match the signed-in ESPN owner to the correct fantasy team. The raw SWID value is not included in the sanitized fantasy-league snapshot sent to The Inner Sanctum.

How information is used

Extension data is used only to provide or improve the user-requested fantasy-league connection and related Inner Sanctum fantasy-football features. The extension is read-only: it does not place transactions, change lineups, add or drop players, or perform other fantasy-provider account actions.

Extension data is not used or transferred for advertising, credit decisions, data brokerage, or unrelated profiling.

Storage

The extension may use Chrome extension storage for short-lived connection state while a user-requested connection flow is in progress. It is not designed to store raw provider passwords or raw ESPN authentication identifiers as part of the fantasy-league snapshot.

Chrome Web Store Limited Use

The use of information received through The Inner Sanctum Connect browser extension will comply with the Chrome Web Store User Data Policy, including the Limited Use requirements. Extension data is used only to provide or improve the user-requested fantasy-league connection and related Inner Sanctum features, except where disclosure is required by law or necessary for security.

Permissions

The extension uses the tabs, scripting, and storage permissions only to find or activate the relevant provider tab, run the read-only connection logic on supported pages, keep short-lived connection state, and deliver the sanitized result to The Inner Sanctum.

Contact

Questions about this browser-extension privacy notice can be submitted through The Inner Sanctum website.
