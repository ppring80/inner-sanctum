# Super SAGE RB Matchup Intelligence V1

RB is modeled as two interacting fantasy roles: rushing + receiving.

Core inputs:
box/front tendencies when sourced; offensive personnel; carries and rush share; targets/routes/route participation; red-zone and goal-line work; game-state splits.

Critical rule:
A poor rushing environment does not automatically make an RB a poor fantasy start when receiving usage provides an independent scoring path.

Guardrails:
box tendency is not rushing efficiency; personnel does not identify the ball carrier; red-zone/goal-line roles require player evidence; historical game script is not a forecast.

Customer presentation remains 1/3/10 followed by opt-in advanced detail.
