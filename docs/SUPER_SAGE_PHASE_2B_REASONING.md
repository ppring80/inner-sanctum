# Super SAGE Phase 2B — Reasoning Bridge

The reasoning bridge converts retrieval results into a safe football-analysis packet.

It deliberately does NOT generate a new fantasy ranking, score, projection or current-team claim.

## Packet sections
- establishedKnowledge
- practitionerEvidence
- researchHypotheses
- limitations
- provenance
- reasoningRules
- nextEvidenceNeeded

## Core boundary
Historical/conceptual football knowledge explains what *could matter*. Current NFL evidence establishes what *is happening now*. Validation establishes whether the interaction improves fantasy decisions.

The bridge therefore requires:
Football knowledge + current evidence -> analysis
Analysis + validation -> possible production insight

Never:
football concept -> automatic ranking adjustment
