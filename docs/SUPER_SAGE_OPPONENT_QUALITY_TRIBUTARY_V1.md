# Super SAGE Opponent-Quality Tributary V1

Purpose: interpret defensive performance in context.

Example motivating case: a defense's pass results against an opponent using a third-string QB should remain in the raw record, but SAGE should also preserve that game context before deciding how representative the result is.

Keep side by side:
- raw defensive performance
- opponent baseline
- opponent-adjusted performance
- verified QB starter/backup/third-string context
- sample size

Never erase a game because the opponent was weak. Never infer QB quality from reputation. This tributary modifies confidence/context, not production rankings by itself.
