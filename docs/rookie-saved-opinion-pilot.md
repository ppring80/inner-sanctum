# Opt-in saved Rookie opinion pilot

The lineup tool accepts optional includeRookieSecondOpinion=true only when a user asks for Rookie's second opinion. Defaults are unchanged. SAGE's authority, lineup, confidence, provisional state, alerts and customerAnswer remain unchanged; an optional separately labelled saved opinion is appended beside them.

This first release is saved-only. It uses the existing enabled reviewer deployment and authenticated linked owner; pasted rosters are excluded. Only the first unresolved pair in the exact current SAGE record can qualify. The owned saved record, frozen parent, focused evidence, prompt/schema fingerprints, current structured answer and factor directions must all validate. Legacy, invalid, stale or another owner's answers are never shown. No unresolved pair skips the read. A missing saved answer returns unavailable. No provider invocation, budget reservation, refresh or new review write is allowed by this path. Existing explicit private generation remains separate and unchanged. The usual lineup evidence snapshot writes remain as before.

Saved confidence is explicitly described as the model's assessment, not a calibrated probability. Customer output includes only labelled lean, confidence, server-rendered facts/reconsideration and context; no raw provider response, keys or evidence packet. Any optional-read failure leaves SAGE's answer intact. The optional read is bounded to 1.5 seconds; a stalled cache cannot hold the lineup response open.

This is a limited opt-in MCP release, not website integration or automatic paid generation. Existing tool connections may need metadata refresh to expose the optional parameter. The historical Allen/Higbee and Miller/Higbee successes do not authorize showing those opinions against a newer decision. Current linked SAGE has all slots decided, so live verification can verify safe skipping, not a real READY customer result. Tests exercise READY with mocked owned saved evidence; report this distinction explicitly. No additional paid live run is part of this release.
