# Super SAGE Injury / Availability Impact Tributary V1

Availability is not merely a status tag. Super SAGE tracks the role removed and only redistributes opportunity when evidence supports it.

Possible lost roles:
snap share, routes, targets, carries, pass protection, pass rush, coverage.

Fantasy channels:
direct availability; teammate opportunity; protection/run blocking; defensive coverage/pass rush; opponent matchup.

Critical rule: the nominal backup does not automatically inherit the starter's complete role.

Material changes trigger re-analysis of affected QB/RB/WR/TE matchup intelligence. Evidence remains timestamped and sourced.
