# Super SAGE Defensive Performance Tributary V1

Purpose: give the Columbia a simple, current defensive-performance baseline before deeper scheme interaction.

Track for every team:
- pass defense: EPA/dropback rank, success allowed, pass yards/game + rank, net yards/dropback, TDs, explosive rate
- run defense: EPA/carry rank, success allowed, rush yards/game + rank, yards/carry, TDs, explosive rate
- overall: defensive EPA/play, success allowed, points allowed/game
- sample: games/dropbacks/rushes
- season + recent 3 + recent 5 windows when available

Critical language rule:
Never say "28th against the pass" without defining the metric. A defense can rank differently by yards, EPA, success, fantasy points or TDs.

Performance rank is a tributary, not a verdict. Join it with scheme, stress, role/opportunity, injuries, opponent quality and position-specific matchup intelligence.

Customer default stays 1/3/10; detailed ranks/rates appear after opt-in.
