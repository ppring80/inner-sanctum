# Super SAGE QB Matchup Intelligence V1

Joins:
1. current defensive scheme/tendency evidence,
2. current offensive structural evidence,
3. historical/current QB stress response.

The engine selects the most relevant verified interaction rather than dumping metrics.

Priority when evidence exists:
pressure-response -> blitz-response -> coverage-structure -> insufficient evidence.

This is an explanation/intelligence layer only. It does not alter Weekly SAGE rankings.

Customer contract:
1 second decision/direction;
3 second primary interaction;
10 second fantasy interpretation/watch item;
then ask whether the customer wants deeper SAGE analysis.

Advanced output preserves metric-level sample/source and never converts missing QB-vs-coverage splits into inferred facts.
