# Super SAGE QB Stress Matrix V1

Separates defensive pressure concepts instead of treating blitz as pressure.

Public-PBP baseline:
- dropbacks
- sacks
- recorded QB hits
- scrambles
- EPA/dropback
- success
- explosive plays
- CPOE where present

The initial disruption proxy is explicitly sack OR recorded QB hit. It must never be labeled as true charted pressure.

Advanced layers:
- charted pressure / time to throw when temporally available
- blitz rate from verified scheme source
- pressure conversion when sourced
- rush-count/four-man pressure when sourced

Customer output remains 1/3/10. Advanced stress metrics appear only after the customer opts in.
