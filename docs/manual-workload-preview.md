# Manual workload preview

Enable `SAGE_MANUAL_WORKLOAD_PREVIEW=true` and a dedicated secret `SAGE_MANUAL_WORKLOAD_TOKEN` only for Deploy Preview functions, then rebuild the draft PR. Never commit the token.

Open `/manual-workload-preview.html`, supply the preview token, and load the running backs for a team and week. This reads the cached Tank01 projection snapshot. The cache entry must have been generated by a build that retains projected carries and targets. The preview also requires a snapshot from before both reports and a kickoff in the future. A missing workload must remain unavailable; do not substitute estimates.

Verify draft preview, approval, withdrawal, and rejection after the snapshot changes. Preview approvals are deploy scoped and do not change customer recommendations.
