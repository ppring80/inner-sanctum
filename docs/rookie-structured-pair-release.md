The model returns selected A/B/null, confidence, decidingFactor, tradeoffFactor, blocker and an enumerated reconsider event. No model prose or citations are accepted. Reconsideration allows a pick being ruled out, confirmed additional work for the alternative, or documented uncertainty about the alternative being resolved. A teammate absence alone is not an event. No diagnoses, opponent statistics or free text can enter the answer. The renderer marks these as future conditions, not current facts. It independently includes required disclosures and supplied role/uncertain availability descriptions; the model cannot suppress them.

All provider transports in these checks are mocked. CI is required before merge.

This constrains explanations to supplied evidence; it does not establish that the selected player will outperform the alternative or that confidence is calibrated. No live calls, refreshes, allowances or budget resets are part of implementation.
